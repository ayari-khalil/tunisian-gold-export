# Tunisian Gold Export

Premium B2B Tunisian Olive Oil Export Platform — Frontend Development Prompt

Build a premium, modern, production-ready B2B website for a Tunisian company specialized in exporting premium Tunisian Extra Virgin Olive Oil to international markets, especially Europe and Africa.

This is not a simple product website or e-commerce store. The goal is to create the digital identity of a serious international export company that can attract importers, distributors, supermarkets, restaurants, hotels, wholesalers, and private-label partners.

The website must communicate:

Tunisian origin + premium quality + authenticity + traceability + professionalism + international logistics + trust.

The design should feel comparable to a premium European food/export company.
